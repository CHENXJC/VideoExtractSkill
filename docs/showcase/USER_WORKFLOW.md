# User Workflow

## 1. Prepare Media

Place image and video files into:

input_media/

## 2. Start the Local Software

Double click:

Start_VideoExtractSkill.cmd

## 3. Run the Full Local Workflow

Click:

One-Click Local Full Workflow

## 4. Review Outputs

Generated reports are saved in:

output/reports/

Batch archives are saved in:

output/reports/batches/

## 5. Optional Direct Run

Without opening the web UI, run:

Run_Local_Full_Workflow.cmd

## 6. Environment Check

Run:

Check_Environment.cmd

## 7. Repair Dependencies

Run:

Repair_Environment.cmd
