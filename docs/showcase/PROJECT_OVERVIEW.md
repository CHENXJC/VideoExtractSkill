# Project Overview

## Name

Batch Media Insight Extractor

## Purpose

This project is a local AI software prototype for batch media understanding.

It helps users process many images and videos at once, extract text and metadata, generate summaries, and export reports.

## Main User Scenario

A user places images and videos into the input_media folder, opens the local web software, and clicks one button to run the full local workflow.

The software then creates structured outputs and Word/PDF reports.

## Portfolio Value

This project demonstrates:

- AI workflow design
- local automation
- batch file processing
- OCR integration
- speech-to-text integration
- report generation
- Streamlit UI development
- Windows local software packaging
- privacy-aware project structure
