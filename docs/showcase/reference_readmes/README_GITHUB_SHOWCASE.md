# Batch Media Insight Extractor

A local AI workflow software prototype for batch image and video information extraction.

## Core Features

- Batch image and video detection
- Image OCR with Chinese and English support
- OCR text cleanup
- Local image summary and keyword extraction
- Video metadata extraction
- Video preview frame generation
- Video audio extraction
- Local Whisper speech-to-text transcription
- Local video transcript summary
- Word and PDF report generation
- Batch report archiving
- Apple-style Streamlit local web interface
- Chinese and English UI switching
- Theme color switching
- One-click local full workflow
- Environment check and repair launchers

## Local-First Strategy

The current version focuses on local functionality. OpenAI or ChatGPT API enhancement is reserved for a future content creation or commercialization stage.

## Privacy Notice

This public showcase version should not include private media files, generated reports, output folders, logs, API keys, or personal data.
