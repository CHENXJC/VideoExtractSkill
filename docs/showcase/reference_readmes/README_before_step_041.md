# Batch Media Insight Extractor\n\nA local-first AI workflow software prototype for batch image and video insight extraction.\n\nThis project turns batches of images and videos into structured text, summaries, keywords, key points, and Word/PDF reports.\n\n## Why This Project Matters\n\nMany users store useful information inside screenshots, images, short videos, lectures, screen recordings, and social media clips. This software prototype helps convert those unstructured media files into searchable, reusable, and report-ready information.\n\n## Core Capabilities\n\n- Batch image and video file detection\n- Image OCR with Chinese and English support\n- OCR text cleanup and formatting\n- Local image summary, keywords, and key point extraction\n- Video metadata extraction\n- Video preview frame generation\n- Video audio extraction\n- Local Whisper speech-to-text transcription\n- Local video transcript summary\n- Word and PDF report generation\n- Batch report archiving\n- Apple-style Streamlit dashboard UI\n- Chinese and English UI switching\n- Theme color switching\n- One-click local full workflow\n- Environment check and repair launchers\n\n## Main Workflow\n\n1. Place images and videos into the local input folder.\n2. Launch the local web software.\n3. Run the one-click local full workflow.\n4. Review extracted text, summaries, keywords, and reports.\n5. Find archived Word/PDF reports in the batch report folder.\n\n## Technical Stack\n\n- Python\n- Streamlit\n- Tesseract OCR\n- faster-whisper\n- OpenCV\n- imageio-ffmpeg\n- pandas\n- python-docx\n- pywin32\n- Windows CMD launchers\n\n## Local-First Strategy\n\nThe current version prioritizes local processing. It does not require OpenAI API credits for the main local workflow.\n\nOpenAI or ChatGPT enhanced summarization is reserved for a later content creation, portfolio demonstration, or commercialization stage.\n\n## Privacy and Safety\n\nThis public showcase version intentionally excludes private media files, generated reports, logs, API keys, and personal data.\n\nExcluded from public release:\n\n- input_media/\n- output/\n- logs/\n- API keys\n- private images\n- private videos\n- generated Word/PDF reports\n- model cache files\n\n## Project Status\n\nCheckpoint: VIDEO-EXTRACT-021\n\nThe current project is a working local software prototype and a GitHub portfolio showcase candidate.\n\n## Future Roadmap\n\n- Improve UI polish and onboarding\n- Add demo data and safe screenshots\n- Add stronger local summarization rules\n- Add optional OpenAI enhanced summary module later\n- Explore Windows packaging and installer options\n- Prepare a polished GitHub portfolio page
