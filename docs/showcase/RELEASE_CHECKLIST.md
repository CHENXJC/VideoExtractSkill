# Release Checklist

Before publishing to GitHub:

- Confirm input_media is excluded.
- Confirm output is excluded.
- Confirm logs are excluded.
- Confirm no API key is included.
- Confirm no private image or video is included.
- Confirm no generated Word or PDF report is included.
- Confirm README_GITHUB_SHOWCASE.md exists.
- Confirm PUBLIC_SHOWCASE_MANIFEST.md exists.
- Confirm docs/showcase files exist.
- Confirm portfolio summary exists.
- Run python run_step_019_pre_publish_check.py before publishing.
