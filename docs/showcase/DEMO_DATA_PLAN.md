# Demo Data Plan

Goal: create safe demo data for public screenshots and GitHub showcase.

## Demo Data Principles

- No private screenshots.
- No private videos.
- No personal names.
- No private conversations.
- No real client data.
- No financial account information.
- No API keys.

## Recommended Demo Files

### Demo Image 1

A clean image containing simple public text, such as a fake meeting note or fake product brief.

Example content:

- Product launch notes
- Three bullet points
- Fake project timeline

### Demo Image 2

A screenshot-style image with English and Chinese text for OCR demonstration.

### Demo Video 1

A short 10 to 30 second demo video with simple spoken content.

Recommended topic:

- Introduction to the software workflow
- Fake product explanation
- Short learning note
