# Workflow History Page

Checkpoint: VIDEO-EXTRACT-030

This step adds a Workflow History page to the local Streamlit software.

New capabilities:

- Show latest local full workflow success status.
- Show image, video, and other file counts from the latest run.
- Show latest batch report folder.
- Show latest log file.
- Show workflow step records.
- Show recent log files.
- Show recent batch report folders.
- Open latest log, latest status file, and latest batch folder.

Product value:

Users can check whether the latest workflow completed successfully without searching through folders manually.
