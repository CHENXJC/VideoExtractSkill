# PUBLIC_SHOWCASE_MANIFEST

This file describes what is safe to include in the public showcase version of Batch Media Insight Extractor.

## Safe to Publish

- README_SHOWCASE.md
- PUBLIC_SHOWCASE_MANIFEST.md
- docs/showcase/
- app.py
- modules/ source files
- launcher scripts
- requirements.txt
- config templates
- assets/app_icon.svg
- run_check_environment.py
- run_launcher.py

## Do Not Publish

- input_media/
- output/
- output/reports/
- output/video_transcripts/
- output/video_audio/
- output/video_frames/
- output/openai_enhanced_summaries/
- logs/
- .env
- API keys
- private media files
- generated Word/PDF reports
- personal screenshots containing private content
- model cache files

## Public Showcase Principle

This GitHub version is intended to show:

- project idea
- software architecture
- technical workflow
- UI design direction
- local AI automation capability
- report generation capability

It is not intended to publish private user data or commercial/private core assets.
