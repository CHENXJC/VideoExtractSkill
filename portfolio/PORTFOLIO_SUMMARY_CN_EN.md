# Portfolio Summary

## Chinese

Batch Media Insight Extractor 是一个本地运行的批量图片与视频信息提取软件原型。它支持图片 OCR、视频信息提取、视频转文字、本地摘要、关键词提取和 Word/PDF 报告生成。

## English

Batch Media Insight Extractor is a local AI software prototype for batch image and video understanding. It supports image OCR, video metadata extraction, Whisper transcription, local summaries, keyword extraction, and Word/PDF report generation.
