# Project Card: Batch Media Insight Extractor

## Category

Local AI Workflow Software / AI Skill / Portfolio Project

## Problem

Images, screenshots, short videos, and screen recordings often contain useful information, but they are hard to search, summarize, reuse, and convert into structured reports.

## Solution

A local-first software prototype that batch-processes images and videos, extracts text and metadata, generates summaries and keywords, and exports Word/PDF reports.

## Key Technologies

- Python
- Streamlit
- Tesseract OCR
- faster-whisper
- OpenCV
- ffmpeg
- python-docx
- pywin32

## Product Value

- Saves time when processing many media files.
- Turns unstructured media into structured knowledge.
- Keeps private files local.
- Produces reusable reports.
- Can be extended into content analysis, learning notes, sales material extraction, or creator workflow tools.
