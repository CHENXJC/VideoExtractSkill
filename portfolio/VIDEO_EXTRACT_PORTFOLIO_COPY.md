# VideoExtract Portfolio Copy

## Short Version

Built a local-first AI workflow software prototype that converts batches of images and videos into structured text, summaries, keywords, and Word/PDF reports.

## Resume Version

Developed a local AI media insight extraction tool using Python, Streamlit, Tesseract OCR, faster-whisper, OpenCV, and Word/PDF automation. The system supports batch image OCR, video transcription, local summarization, report generation, environment checks, and privacy-aware GitHub showcase packaging.

## Chinese Version

开发了一个本地运行的批量图片与视频信息提取软件原型，支持图片 OCR、视频转文字、本地摘要、关键词提取、Word/PDF 报告生成、批次归档和 Apple 风格网页 UI。项目采用本地优先策略，避免公开私人媒体和生成报告。

## Product Angle

This project can be positioned as a media-to-knowledge automation tool for creators, students, researchers, sales teams, and knowledge workers.
